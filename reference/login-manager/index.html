    class OAuthLoginManager:
    """OAuth Login Manager for Flask integration."""

    def __init__(
            self,
            campus_client: campus_python.Campus | None = None,
            default_endpoint: str = "index",
            login_scopes: "list[str] | None" = None,
            login_prefix: str | None = None,
    ):
        """Initialize the OAuthLoginManager.

        Args:
            campus_client: Optional Campus client instance. If None, a
                new instance will be created.
            default_endpoint: Default endpoint to redirect to after login/logout
            login_scopes: OAuth scopes the /login flow requests for the
                minted user credential (rides start_login's scopes
                parameter). None keeps ["campus.profile"]. Apps whose
                features need management scopes on the user's token
                (#865/#883 two-leg model) pass the full list — and
                must extend their client's allowed_scopes cap BEFORE
                deploying, since campus.auth validates the request
                against that cap fail-closed.
            login_prefix: Mount prefix for the auth blueprint
                (flask-campus#47). "timetable", "/timetable" and
                "/timetable/" are equivalent; the default (None/'')
                mounts /login, /finalize_login and /logout at the host
                root — the standalone behavior every existing consumer
                keeps. Header-less deployments ONLY: a foreign
                path-dispatching proxy that does not set
                X-Forwarded-Prefix, or a standalone deployment that
                wants a namespaced auth surface on its own origin.
                Behind campus-gateway, do NOT set it — init_app already
                installs PrefixFix (flask-campus#50), which derives the
                namespace from X-Forwarded-Prefix, and combining the
                two doubles the namespace: PrefixFix strips one /<ns>,
                so the statically mounted /<ns>/login never matches
                while url_for emits SCRIPT_NAME + mount. See
                docs/url-namespacing.md in the campus repo. The OAuth
                callback URL (url.full_url_for) and every
                login_required redirect follow the prefix
                automatically. PUBLIC_URL stays a bare origin — the
                callback is PUBLIC_URL + prefix.
        """
        # Do-not-combine guard: a static login_prefix mount behind
        # campus-gateway doubles the namespace (PrefixFix already
        # namespaces from X-Forwarded-Prefix, fc#50), so flag it at
        # construction — the docstring-only rule was easy to miss.
        if login_prefix is not None:
            logger.warning(
                "login_prefix=%r is only for header-less deployments "
                "(a foreign path-dispatching proxy without "
                "X-Forwarded-Prefix, or a standalone namespaced auth "
                "surface). Behind campus-gateway, remove it: init_app "
                "installs PrefixFix (flask-campus#50), which derives "
                "the namespace from X-Forwarded-Prefix, and combining "
                "the two doubles the namespace. See "
                "docs/url-namespacing.md in the campus repo.",
                login_prefix,
            )
        if isinstance(campus_client, campus_python.Campus) or campus_client is None:
            # Real Campus client: the framework gets its own instance.
            self.campus = campus_client or campus_python.Campus()
            # Framework-owned client (flask-campus#40): every call
            # flask_campus makes itself — the context push, the login
            # flow, circle-membership probes — runs on this instance,
            # never on the host's shared client. Hosts drive their
            # client with user/app session blocks from gthread request
            # threads, leaving whatever credential the current block
            # holds on it; the framework's ambient calls (identity
            # resolution, session finalize) must always present the
            # client credential — campus.auth denies user principals on
            # session-flow routes (#854/#1055), and a poisoned
            # resolution loops the browser into /login (classroom#153).
            # The session-id provider seam installed at init_app is
            # global, so this instance resolves the same flask.session
            # ids as the host's client.
            self._framework_campus = campus_python.Campus()
        else:
            # Duck-typed client (test doubles, stub harnesses): there is
            # no real Campus to isolate from, so framework calls use it
            # directly and keep exercising the double.
            self.campus = campus_client
            self._framework_campus = campus_client
        self.default_endpoint = default_endpoint
        self.login_scopes = login_scopes
        # Explicit argument beats the env ("" disables an env-set
        # prefix); both normalize to '' (standalone) or '/x'.
        self.login_prefix = _normalize_prefix(
            login_prefix
            if login_prefix is not None
            else env.get("LOGIN_URL_PREFIX")
        )
        self._cache = context.UserCache()
        self._circle_cache = circles.MembersCache()

    def _push_context_hook(self) -> None:
        """App-wide before_request hook that pushes the auth context.

        Static asset requests never read g.user, so they skip the
        upstream auth lookup (#689): a session-carrying browser
        otherwise pays push_context's auth API calls on every stylesheet
        and script, which can wedge a sync worker under load.
        """
        endpoint = flask.request.endpoint or ""
        if endpoint == "static" or endpoint.endswith(".static"):
            return
        # Framework-owned instance, NOT self.campus (#40): the host's
        # client may be mid with_user_session() block on another gthread
        # request, carrying that block's user bearer — an ambient call
        # on it would present the wrong principal and campus.auth would
        # deny session-flow routes (#854/#1055), bricking this request
        # into the /login loop (classroom#153). Do not swap these call
        # sites back to self.campus; see the init comment above.
        context.push_context(self._framework_campus, self._cache)

        # Span identity (#820): the audit tracing middleware reads
        # g.user_id / g.client_id when building this request's span.
        # Page loads are the waterfall roots, so stamping them here is
        # what lets the audit UI attribute a page load to the app's
        # client and the signed-in user.
        user = getattr(flask.g, "user", None)
        if user is not None and getattr(user, "id", None):
            flask.g.user_id = user.id
        client_id = env.get("CLIENT_ID")
        if client_id:
            flask.g.client_id = client_id

    def init_app(self, app: flask.Flask | flask.Blueprint):
        """Initialize the login manager with the Flask app.

        On a Flask app this also installs the PrefixFix middleware
        (flask-campus#50): X-Forwarded-Prefix from a path-dispatching
        gateway moves into SCRIPT_NAME, making every url_for — static
        assets, links, and this blueprint's routes — namespace-aware
        with no per-app configuration. No-op when the header is absent
        (standalone and origin-domain deployments).
        """
        # The SDK resources resolve their session ids through this
        # module's flask.session storage from here on (idempotent).
        context.install_session_provider()
        # Gateway subpath mounting (#50): wrap before anything else so
        # the namespace is in place for all downstream routing and URL
        # generation. Flask only — a Blueprint has no wsgi_app to wrap.
        if isinstance(app, flask.Flask):
            app.wsgi_app = PrefixFix(app.wsgi_app)
        # The login flow rides the framework instance too (#40): its
        # sessions.new/finalize/logins.new calls are session-flow routes
        # that campus.auth only accepts from the owning client — exactly
        # the credential an interleaved host session block would displace.
        bp = _create_bp(
            self._push_context_hook, self._framework_campus, self._cache,
            self.default_endpoint, login_scopes=self.login_scopes,
            url_prefix=self.login_prefix or "/",
            default_next=self.login_prefix + "/" if self.login_prefix else "/",
        )
        app.register_blueprint(bp)
        if isinstance(app, flask.Flask):
            app.before_request(self._push_context_hook)
        elif isinstance(app, flask.Blueprint):
            app.before_app_request(self._push_context_hook)

    def login_required(self, view: Callable) -> Callable:
        """Decorator to protect routes that require authentication.

        This gate is IDENTITY-only (#1096 contract): a session whose
        campus grant has died still resolves to a user, so the view
        runs and any token mint inside it fails there. Hosts that mint
        user credentials own the translation of that failure into a
        re-auth flow — classify with
        campus.flask_campus.is_reauth_required (the shared classifier;
        campus-classroom's /api/ 401 + browser-redirect degrade is the
        reference implementation, #98).
        """
        @wraps(view)
        def wrapped_view(*args, **kwargs):
            """Redirect signed-out users to sign-in, else run the view."""
            if not hasattr(flask.g, "user") or flask.g.user is None:
                return flask.redirect(
                    flask.url_for('auth.login', next=flask.request.path)
                )
            return view(*args, **kwargs)
        return wrapped_view

    def circle_member_required(self, circle: str) -> Callable:
        """Decorator: the view requires membership in a named circle.

        View-level gating over campus.api circles (the domain access
        control): the signed-in user's ID — their email, which is also
        their user circle's name — must be a member of `circle`
        (e.g. "campus-admin" or a role circle "timetable.admin"). Use
        circle_admin_required for the per-resource admin roles.

        Enforcement stays in campus.api: this gate renders the right
        UI before the API's 403 wall and must never be the only
        protection for data.

        Signed-out users redirect to sign-in (the login_required
        behaviour, folded in so decorator stacking order never
        matters). Signed-in non-members get 403 — they are
        authenticated, not unknown. If the circles backend cannot
        answer (network, API error), the view fails closed with 503
        rather than a misleading 403; answers are cached briefly
        (circles.MembersCache) so warm views make no upstream calls.
        """
        def decorator(view: Callable) -> Callable:
            @wraps(view)
            def wrapped_view(*args, **kwargs):
                """Gate the view on sign-in + circle membership."""
                user = getattr(flask.g, "user", None)
                if user is None:
                    return flask.redirect(
                        flask.url_for('auth.login', next=flask.request.path)
                    )
                user_id = getattr(user, "id", None)
                if not user_id:
                    flask.abort(403, description=(
                        "Signed-in identity has no user ID; membership "
                        f"in '{circle}' cannot be verified."
                    ))
                try:
                    # is_member opens its own with_user_session() (#40):
                    # keep that mint+read off the host's shared client.
                    member = circles.is_member(
                        self._framework_campus, self._circle_cache, circle, user_id
                    )
                except circles.CirclesUnavailableError as err:
                    flask.current_app.logger.error(
                        "Circle membership unavailable: %s", err
                    )
                    flask.abort(503, description=(
                        "Authorization backend unavailable; "
                        "try again shortly."
                    ))
                if not member:
                    flask.abort(403, description=(
                        f"Membership in the '{circle}' circle is required."
                    ))
                return view(*args, **kwargs)
            return wrapped_view
        return decorator

    def circle_admin_required(self, resource: str) -> Callable:
        """Decorator: the view requires the <resource>.admin role.

        Convenience over circle_member_required for the circles
        bootstrap's per-resource role circles: circle_admin_required(
        "timetable") gates on membership in the "timetable.admin"
        circle — the same role campus.api's mutation routes enforce
        server-side (campus/api/authz.py require_resource_admin).
        """
        return self.circle_member_required(f"{resource}.admin")

    def login_required(self, view: Callable) -> Callable:
    """Decorator to protect routes that require authentication.

    This gate is IDENTITY-only (#1096 contract): a session whose
    campus grant has died still resolves to a user, so the view

    reference implementation, #98).

                flask.url_for('auth.login', next=flask.request.path)
            )
        return view(*args, **kwargs)

    def circle_member_required(self, circle: str) -> Callable:
    """Decorator: the view requires membership in a named circle.

    View-level gating over campus.api circles (the domain access
    control): the signed-in user's ID — their email, which is also
    their user circle's name — must be a member of `circle`
    (e.g. "campus-admin" or a role circle "timetable.admin"). Use
    circle_admin_required for the per-resource admin roles.

    Enforcement stays in campus.api: this gate renders the right
    UI before the API's 403 wall and must never be the only
    protection for data.

    Signed-out users redirect to sign-in (the login_required
    behaviour, folded in so decorator stacking order never
    matters). Signed-in non-members get 403 — they are
    authenticated, not unknown. If the circles backend cannot
    answer (network, API error), the view fails closed with 503
    rather than a misleading 403; answers are cached briefly
    (circles.MembersCache) so warm views make no upstream calls.
    """
    def decorator(view: Callable) -> Callable:
        @wraps(view)
        def wrapped_view(*args, **kwargs):
            """Gate the view on sign-in + circle membership."""
            user = getattr(flask.g, "user", None)
            if user is None:
                return flask.redirect(
                    flask.url_for('auth.login', next=flask.request.path)
                )
            user_id = getattr(user, "id", None)
            if not user_id:
                flask.abort(403, description=(
                    "Signed-in identity has no user ID; membership "
                    f"in '{circle}' cannot be verified."
                ))
            try:
                # is_member opens its own with_user_session() (#40):
                # keep that mint+read off the host's shared client.
                member = circles.is_member(
                    self._framework_campus, self._circle_cache, circle, user_id
                )
            except circles.CirclesUnavailableError as err:
                flask.current_app.logger.error(
                    "Circle membership unavailable: %s", err
                )
                flask.abort(503, description=(
                    "Authorization backend unavailable; "
                    "try again shortly."
                ))
            if not member:
                flask.abort(403, description=(
                    f"Membership in the '{circle}' circle is required."
                ))
            return view(*args, **kwargs)
        return wrapped_view
    return decorator

    campus.flask_campus.context

    Auth session-context mechanics for Flask hosts.

    This module owns the client-side half of the campus login flow: the storage of the auth-session and login-session ids (flask.session, via the SDK's SESSION_STORAGE_KEY / LOGIN_STORAGE_KEY), the request-entry context push (g.user / g.device with a per-manager user cache), and the login-flow steps (start / finalize / logout).     OAuthLoginManager wires this module in at init_app; apps never call it directly. The SDK's session-id provider seam is installed here, so the SDK resources resolve their ids from the same flask.session keys this module writes — during the rollout window both sides write identical values (idempotent), and after the SDK sheds its flask lane this module is the sole owner.

    class UserCache:
    """Process-local cache of resolved session users (#57 semantics).

    Entries snapshot the user via to_resource() and are rehydrated per
    hit, so callers cannot poison the cache by mutating flask.g.user.
    """

    def __init__(self, ttl_seconds: float = USER_CACHE_TTL_SECONDS):
        self.ttl_seconds = ttl_seconds
        # (kind, session_id) -> (expires_at, user snapshot, device_id).
        self._entries: dict[
            tuple[str, str],
            tuple[float, object, str | None],
        ] = {}

    def get(
            self, kind: str, session_id: str | None
    ) -> tuple[object, str | None] | None:
        """The cached (user, device_id) for a session, or None.

        Expired entries are dropped lazily on read.
        """
        if session_id is None:
            return None
        entry = self._entries.get((kind, session_id))
        if entry is None:
            return None
        expires_at, snapshot, device_id = entry
        if time.monotonic() >= expires_at:
            self._entries.pop((kind, session_id), None)
            return None
        user = (
            campus.model.User.from_resource(snapshot)
            if isinstance(snapshot, dict)
            else snapshot
        )
        return user, device_id

    def put(
            self,
            kind: str,
            session_id: str | None,
            user: object,
            device_id: str | None,
    ) -> None:
        """Cache a session's resolved user for ttl_seconds."""
        if session_id is None:
            return
        snapshot: object = (
            user.to_resource()
            if isinstance(user, _Snapshottable)
            else user
        )
        self._entries[(kind, session_id)] = (
            time.monotonic() + self.ttl_seconds,
            snapshot,
            device_id,
        )

    def pop(self, kind: str, session_id: str | None) -> None:
        """Drop a session's cached user (logout, stale session)."""
        if session_id is not None:
            self._entries.pop((kind, session_id), None)

    def push_context(campus: campus_python.Campus, cache: UserCache) -> None:
    """Push auth/login context to flask.g (the SDK push_context port).

    Resolved users are cached per session for UserCache's ttl (#57):
    warm requests make zero upstream calls. Trade-off: a session
    revoked server-side — not through logout(), which evicts
    immediately — keeps resolving for up to the TTL window.

    Resolution failures degrade to anonymous (#28): a cookie whose
    session/login cannot be resolved — gone (404), denied (#854
    owning-client checks), or unreachable (gateway 502, malformed
    response) — must never propagate out of this app-wide hook, or
    the browser is bricked on every route including /logout. The
    reference is dropped and the request flows to the app's auth
    gate, which redirects to login.
    """
    flask.g.user = None
    flask.g.device = None

    # Try to load auth session if one exists
    if campus.auth.sessions.has_session():
        session_id = flask.session.get(SESSION_STORAGE_KEY)
        cached = cache.get(LANE_SESSION, session_id)
        if cached is not None:
            flask.g.user, flask.g.device = cached
            return
        try:
            auth_session = campus.auth.sessions.from_session()
            if auth_session.user_id:
                # The auth service embeds the session user for the
                # owning client (#879); the operator-gated users route
                # remains the fallback for older auth services.
                user = (
                    getattr(auth_session, "user", None)
                    or campus.auth.users[auth_session.user_id].get()
                )
                flask.g.user = user
                cache.put(LANE_SESSION, session_id, user, None)
        except campus_python.errors.NotFoundError:
            # Session no longer exists on server (expired, restart, etc.)
            _forget(cache, LANE_SESSION, session_id)
        except Exception as exc:
            logger.warning(
                f"Auth session resolution failed ({session_id}): "
                f"{type(exc).__name__}: {exc}"
            )
            _forget(cache, LANE_SESSION, session_id)

    # Try to load login session if one exists
    elif campus.auth.logins.has_session():
        login_id = flask.session.get(LOGIN_STORAGE_KEY)
        cached = cache.get(LANE_LOGIN, login_id)
        if cached is not None:
            flask.g.user, flask.g.device = cached
            return
        try:
            login_session = campus.auth.logins.from_session()
            login_user_id = login_session.user_id
            # Embedded login user (#879) with the same fallback.
            user = getattr(login_session, "user", None)
            if user is None and login_user_id is not None:
                user = campus.auth.users[login_user_id].get()
            flask.g.user = user
            flask.g.device = login_session.device_id
            if user is not None:
                cache.put(
                    LANE_LOGIN, login_id, user, login_session.device_id
                )
        except campus_python.errors.NotFoundError:
            # Login session no longer exists on server
            _forget(cache, LANE_LOGIN, login_id)
        except Exception as exc:
            logger.warning(
                f"Login session resolution failed ({login_id}): "
                f"{type(exc).__name__}: {exc}"
            )
            _forget(cache, LANE_LOGIN, login_id)

    we proxied through requests, Google detects a server user agent and
    switches to OAuth Lite flow which breaks in browsers (500 error).

    auth_session = campus.auth.sessions.new(
        redirect_uri=target,
        scopes=scopes or DEFAULT_LOGIN_SCOPES,
        target=target,

    # with the same value during the compat window (idempotent).

        "response_type": "code",  # OAuth2 authorization code flow
        "redirect_uri": target,  # Callback URL after auth
        "state": auth_session.id,
    }
    return flask.redirect(f"{authorize_url}?{urlencode(params)}")

    def finalize_login(
        campus: campus_python.Campus,
        *,
        state: str,
        code: str,
        scope: str,
) -> None:
    """Complete an authorization flow (the SDK finalize port).

    Steps: validate the auth session, exchange the code (credentials
    are stored server-side by the token endpoint), finalize the
    session, provision the user, create the login session — the
    device id rides the auth session (#825: campus.auth observed the
    campus_device cookie at /authorize; the minted fallback keeps
    non-cookie flows working).

    Raises:
        campus_python.errors.BadRequestError / AuthenticationError:
            rejected codes (replayed, expired) or a state mismatch —
            routine in a browser flow; callers send the user back to
            sign-in (#690).

    Args:
        state: The OAuth state parameter (the auth session id).
        code: The authorization code from the OAuth callback.
        scope: Granted OAuth scopes (accepted for flow compatibility;
            the grant itself is recorded server-side).
    """
    # 1. Validate auth session
    auth_session = campus.auth.sessions.from_code(code=code)
    if auth_session.id != state:
        raise campus_python.errors.AuthenticationError(
            error_description="State parameter does not match session ID."
        )
    if auth_session.user_id is None:
        raise campus_python.errors.AuthenticationError(
            error_description="Unidentified user from auth session"
        )

    # 2. Exchange authorization code for access token
    campus.auth.exchange_code_for_token(
        code=code,
        redirect_uri=auth_session.redirect_uri,
    )

    # 3. Finalize session; the response embeds the session user for
    # the owning client (#879). Pre-#879 services return no user.
    _target, session_user = campus.auth.sessions[auth_session.id].finalize()

    # 4. Ensure user exists (the server provisions the user record
    # during verify_login; a missing user is a hard error here).
    if session_user is None:
        campus.auth.users[auth_session.user_id].get()

    # The auth session is consumed — clear its storage key (the SDK's
    # finalize() pops the same key during the compat window).
    flask.session.pop(SESSION_STORAGE_KEY, None)

    # 5. Create the login session
    login_session = campus.auth.logins.new(
        user_id=auth_session.user_id,
        device_id=(
            auth_session.device_id
            or uid.generate_category_uid("device", length=16)
        ),
        agent_string=flask.request.headers.get("User-Agent", ""),
    )
    flask.session[LOGIN_STORAGE_KEY] = login_session.id

    def logout(
        campus: campus_python.Campus,
        cache: UserCache | None = None,
) -> None:
    """Logout the current user (the SDK logout port).

    Revokes the login session through the API, then clears local
    state. Remote revocation is best-effort: the login session may
    already be gone server-side (expired, swept, or the client's auth
    service session cookie lost across app workers), but the local
    session state is always cleared so the user is signed out locally
    regardless of the revocation outcome.
    """
    flask.g.pop("user", None)
    flask.g.pop("device", None)
    if not campus.auth.logins.has_session():
        return
    try:
        login_session = campus.auth.logins.from_session()
        campus.auth.logins[login_session.id].revoke()
        if cache is not None:
            cache.pop(LANE_LOGIN, login_session.id)
    except Exception as err:
        logger.warning(
            "Login session revocation failed (continuing with local "
            "logout): %s", err
        )
        flask.session.pop(LOGIN_STORAGE_KEY, None)
    # The SDK's revoke() pops the same key during the compat window;
    # this module is the owner, so clear it unconditionally.
    flask.session.pop(LOGIN_STORAGE_KEY, None)

    is_reauth_required(err: BaseException) -> bool ¶

    True when an SDK error means the browser must sign in again.

    The #1096 contract, codified: identity resolution (push_context) is capability-independent — a session whose grant has died still resolves to a user, so login_required passes and the token-mint failure surfaces later, inside the route's own Campus work. Hosts that mint user credentials (with_user_session and friends) own the translation of that failure into a re-auth flow; this helper is the shared classifier so every host makes the same call on the same shapes.

    Three shapes mean re-auth, never retry:

    • OAuth invalid_grant: the login-session token route reports a dead login session or a missing/expired campus grant as a 400 with this OAuth error (#98).
    • AuthenticationError mentioning the login session id: the flask session lost its stored login/session ids entirely — the SDK raises before any HTTP call (the 2026-11-13 classroom 500s).
    • AccessDeniedError mentioning sessions:read: a login session row that died server-side makes the auth store answer the mint's session lookup with a denial.

    Network failures, 5xx and rate limits are deliberately NOT re-auth: those are retry/502 territory.

    Keep this helper even where it looks unused: it is exported public interface (pinned by the interface manifest) and is the one shared implementation of the #1096 decision — deleting it re-scatters the classification across hosts (campus-classroom's local copy in apps/classroom/campus_session.py is deleted in favor of this on the next flask-campus pin bump). Before touching the three re-auth shapes, re-read classroom#153/campus#1096: each encodes a live prod failure class.
